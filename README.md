# Tropical Braille Band

Application d’entraînement à la trompette du **Tropical Brass Band**, pensée pour les musiciens aveugles (lecteur d’écran VoiceOver ou NVDA) et malvoyants (affichage géant).

**Ouvrir l’application :** https://sebtronlyon.github.io/Tropical-Braille-Band/

## Ce qu’elle fait
- Importe une partition `.mid`, MusicXML `.xml`/`.musicxml` ou `.mxl` (Logic Pro, MuseScore).
- Affiche la partition en ut pour trompette en si♭, une mesure à la fois, avec la note en très gros et son doigté.
- Lecture, pause, stop, mesure par mesure, tempo réglable (50 % au départ), métronome, accords.
- Accordeur au micro qui annonce la note jouée et sa justesse.
- « Mes morceaux » : bibliothèque enregistrée dans le navigateur, avec les réglages de chaque morceau.
- Export MusicXML pour MuseScore (puis braille musical .brf depuis MuseScore).

Tout tient dans le seul fichier `index.html`, qui fonctionne aussi hors connexion une fois chargé.
